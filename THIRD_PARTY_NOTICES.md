# Upstream attribution

The uploaded starting project was Tiago Moreira's Black-Scholes Calculator:
https://github.com/TFSM00/Black-Scholes-Calculator

Its MIT license, copyright (c) 2022 Tiago Filipe Silva Moreira, is preserved
verbatim in LICENSE.txt. The original project supplied the Streamlit calculator
concept, helper naming, and reference images. The starting README credited the
formula images to https://www.macroption.com/black-scholes-formula/; those legacy
image files are retained unchanged and are not used by the revised application.

This version restructures the implementation into a reusable package and adds
dividend-adjusted pricing, explicit boundary semantics, numerical verification,
IV diagnostics, snapshot acquisition/replay, empirical reporting, tests, and an
updated dashboard. Retain this attribution when describing the project publicly;
the uploaded upstream calculator should not be represented as original work.
